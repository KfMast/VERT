# VERT 项目纯前端视频转换实现文档
## 1. 项目概述
VERT 项目实现了 纯前端的视频格式转换功能 ，无需依赖外部服务器，所有转换操作均在用户浏览器中完成。这一实现利用了 WebAssembly 技术，将 FFmpeg 这一强大的多媒体处理工具移植到浏览器环境中。

## 2. 技术栈
技术/库 版本 用途 来源 @ffmpeg/ffmpeg ^0.12.15 核心视频转换库 package.json:42 @ffmpeg/util ^0.12.2 FFmpeg 辅助工具 package.json:43 WebAssembly - 执行 FFmpeg 核心 浏览器内置 Svelte 5 ^5.43.14 前端框架 package.json:32 TypeScript ^5.9.3 类型系统 package.json:35

### 4.2 2. 执行转换
核心代码 ：

```
public async convert(input: VertFile, to: string): Promise<VertFile> {
    if (!to.startsWith(".")) to = `.${to}`;
    const isAlac = to === ".alac";
    if (isAlac) to = ".m4a";

    let conversionError: string | null = null;
    const ffmpeg = await this.setupFFmpeg(input);
    this.activeConversions.set(input.id, ffmpeg);

    // 监听错误
    const errorListener = (l: { message: string }) => {
        // 错误处理逻辑
    };
    ffmpeg.on("log", errorListener);

    // 写入文件到虚拟文件系统
    const buf = new Uint8Array(await input.file.arrayBuffer());
    await ffmpeg.writeFile("input", buf);

    // 构建并执行转换命令
    const command = await this.buildConversionCommand(ffmpeg, input, 
    to, isAlac);
    await ffmpeg.exec(command);

    // 读取转换结果
    const output = (await ffmpeg.readFile("output" + to)) as unknown as 
    Uint8Array;
    
    // 清理资源
    ffmpeg.off("log", errorListener);
    ffmpeg.terminate();

    // 返回转换后的文件
    const outputFileName = input.name.split(".").slice(0, -1).join(".") 
    + to;
    const outBuf = new Uint8Array(output).buffer.slice(0);
    return new VertFile(new File([outBuf], outputFileName), to);
}
```

### 4.3 3. 构建转换命令
核心代码 ：

```
private async buildConversionCommand(
    ffmpeg: FFmpeg,
    input: VertFile,
    to: string,
    isAlac: boolean = false,
): Promise<string[]> {
    const inputFormat = input.from.slice(1);
    const outputFormat = to.slice(1);

    // 视频到音频转换
    if (videoFormats.includes(inputFormat)) {
        log(["converters", this.name], `Converting video ${input.from} 
        to audio ${to}`);
        return [
            "-i", "input", // 输入文件
            "-map", "0:a:0", // 映射第一个音频流
            ...metadataArgs, // 元数据参数
            ...audioBitrateArgs, // 比特率参数
            ...sampleRateArgs, // 采样率参数
            "output" + to, // 输出文件
        ];
    }

    // 音频到视频转换
    if (videoFormats.includes(outputFormat)) {
        log(["converters", this.name], `Converting audio ${input.from} 
        to video ${to}`);
        
        // 尝试提取专辑封面
        const hasAlbumArt = keepMetadata
            ? await this.extractAlbumArt(ffmpeg)
            : false;
        const codecArgs = toArgs(to, isAlac);

        if (hasAlbumArt) {
            // 使用专辑封面作为视频背景
            return [
                "-loop", "1", // 循环图片
                "-i", "cover.jpg", // 专辑封面
                "-i", "input", // 音频文件
                "-vf", "scale=trunc(iw/2)*2:trunc(ih/2)*2", // 调整尺寸为
                偶数
                "-shortest", // 以最短的流为准
                "-pix_fmt", "yuv420p", // 像素格式
                "-r", "1", // 帧率 1 fps
                ...codecArgs, // 编解码器参数
                ...metadataArgs, // 元数据参数
                ...audioBitrateArgs, // 比特率参数
                ...sampleRateArgs, // 采样率参数
                "output" + to, // 输出文件
            ];
        } else {
            // 使用纯色背景
            return [
                "-f", "lavfi", // 使用 lavfi 滤镜
                "-i", "color=c=black:s=512x512:rate=1", // 黑色背景 
                512x512 1fps
                "-i", "input", // 音频文件
                "-shortest", // 以最短的流为准
                "-pix_fmt", "yuv420p", // 像素格式
                "-r", "1", // 帧率 1 fps
                ...toArgs(to, isAlac), // 编解码器参数
                ...metadataArgs, // 元数据参数
                ...audioBitrateArgs, // 比特率参数
                ...sampleRateArgs, // 采样率参数
                "output" + to, // 输出文件
            ];
        }
    }
}

### 4.4 4. 设置 FFmpeg 实例
核心代码 ：

```
private async setupFFmpeg(input: VertFile): Promise<FFmpeg> {
    // 创建新的 FFmpeg 实例
    const ffmpeg = new FFmpeg();

    // 监听转换进度
    ffmpeg.on("progress", (progress) => {
        input.progress = progress.progress * 100;
    });

    // 监听日志输出
    ffmpeg.on("log", (l) => {
        log(["converters", this.name], l.message);
    });

    // 加载 FFmpeg 核心
    const baseURL = "https://cdn.jsdelivr.net/npm/@ffmpeg/core@0.12.10/
    dist/esm";
    await ffmpeg.load({
        coreURL: `${baseURL}/ffmpeg-core.js`,
        wasmURL: `${baseURL}/ffmpeg-core.wasm`,
    });

    return ffmpeg;
}

## 5. 完整转换流程
1. 用户选择文件 ：通过上传组件选择要转换的视频文件
2. 文件分析 ：系统自动识别文件类型并分配 FFmpegConverter
3. 格式选择 ：用户选择目标视频格式
4. 开始转换 ：用户点击转换按钮，触发 file.convert() 方法
5. FFmpeg 初始化 ：创建 FFmpeg 实例并加载 WebAssembly 核心
6. 文件处理 ：将文件写入 FFmpeg 虚拟文件系统
7. 命令执行 ：构建并执行 FFmpeg 转换命令
8. 进度更新 ：实时显示转换进度
9. 结果生成 ：读取转换结果并创建新文件
10. 下载选项 ：转换完成后，用户可以下载转换后的文件
## 6. 支持的转换类型
转换类型 描述 实现方式 视频 → 视频 不同视频格式之间的转换 直接使用 FFmpeg 命令转换 视频 → 音频 从视频中提取音频轨道 使用 -map 0:a:0 映射音频流 音频 → 视频 将音频转换为视频 使用专辑封面或纯色背景 音频 → 音频 不同音频格式之间的转换 直接使用 FFmpeg 命令转换

## 7. 性能与优化考虑
### 7.1 性能瓶颈
1. WebAssembly 执行速度 ：相比原生代码，WebAssembly 在浏览器中的执行速度较慢
2. 内存限制 ：浏览器对 WebAssembly 模块的内存使用有限制
3. 文件大小 ：大型视频文件可能导致内存不足
4. CPU 使用率 ：转换过程可能占用大量 CPU 资源，影响用户体验
### 7.2 优化措施
1. 使用独立实例 ：为每个转换任务创建独立的 FFmpeg 实例
2. 进度监控 ：实时显示转换进度，提升用户体验
3. 错误处理 ：完善的错误处理机制，确保转换过程稳定
4. 资源清理 ：转换完成后及时清理资源，释放内存
## 8. 优缺点分析
### 8.1 优点
1. 无需服务器 ：完全在客户端执行，无需后端服务器支持
2. 隐私安全 ：文件不会上传到任何服务器，保护用户隐私
3. 离线可用 ：一旦加载完成，可在离线状态下使用
4. 易于部署 ：无需配置后端服务，简化部署流程
5. 跨平台 ：在支持 WebAssembly 的现代浏览器中均可使用
### 8.2 缺点
1. 性能较慢 ：相比服务器端转换，速度较慢
2. 格式限制 ：受限于 FFmpeg WebAssembly 版本支持的格式
3. 内存限制 ：无法处理过大的视频文件
4. 加载时间 ：首次使用需要下载较大的 WebAssembly 文件
5. 浏览器兼容性 ：依赖现代浏览器对 WebAssembly 的支持
## 9. 代码优化建议
1. 缓存机制 ：
   
   - 实现 FFmpeg 实例池，避免频繁创建和销毁实例
   - 缓存常用格式的转换配置，减少重复计算
2. 性能优化 ：
   
   - 实现分块处理大文件，避免内存溢出
   - 利用 Web Workers 进一步提高并发处理能力
3. 用户体验 ：
   
   - 添加转换速度预估功能
   - 实现暂停/恢复转换的功能
   - 添加批量转换支持，提高效率
4. 错误处理 ：
   
   - 增强错误检测和提示，提供更详细的错误信息
   - 实现自动重试机制，提高转换成功率
5. 功能扩展 ：
   
   - 添加视频剪辑、合并功能
   - 支持视频滤镜和特效
   - 实现视频压缩功能，控制输出文件大小
## 10. 总结
VERT 项目的纯前端视频转换实现是一项技术创新，通过 WebAssembly 技术将 FFmpeg 移植到浏览器环境，实现了无需服务器的视频格式转换功能。这一实现不仅保护了用户隐私，也简化了部署流程，为用户提供了便捷的视频处理工具。

虽然在性能和格式支持方面存在一定限制，但随着 WebAssembly 技术的不断发展和浏览器性能的提升，纯前端视频处理有望在未来成为主流解决方案。
